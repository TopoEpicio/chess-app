Shared Requirements (All Variants)

Fuller Pages

No dead space. Persistent nav, rich headers, KPI/telemetry rows, multiple info layers, footer/status bar. Every page feels like a complete product.

Analysis Content

Board with arrows, eval bar + live depth, toolbar, 3 engine lines with SAN, 5 tabs (Riepilogo/Grafico/Mosse/Freece/Coach), move list, stats, classifications, coach insight, actions.

System Strip

Bottom section showing Home/Studio/Puzzles thumbnails in the same visual language, plus design token reference (type scale, color swatches, spacing/radius).

Responsive

Desktop (1440px) and mobile (390px) — columns stack, board scales, no horizontal scroll. Touch-friendly targets, readable type at all sizes.

Accessibility

Semantic HTML, ARIA labels/roles, focus-visible states, contrast ratios, keyboard navigation, reduced-motion support, Italian content throughout.

Technical

Single index.html + assets/ per variant. Vanilla JS for tabs only. CSS Grid/Flexbox. Google Fonts via CDN. Chessboard = CSS grid + Unicode pieces + SVG arrows. No frameworks, no build step.
